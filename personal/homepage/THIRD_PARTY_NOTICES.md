# Visual source notices

The page layout is inspired by [Takuya Matsuyama's homepage](https://www.craftz.dog/) and [its MIT-licensed source](https://github.com/craftzdog/craftzdog-homepage). No dog model or site code is included.

The 3D Scholay rhino hero is rendered from the local Scholay Rhino model. Its cap adapts **“Cap” by J-Toastie**, published on [Poly Pizza](https://poly.pizza/m/aWxhfEnYwl), under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Scholay modified the cap geometry, fit, materials and details for the rhino. J-Toastie does not endorse this adaptation.

The 2D rhino images come from the local Scholay Rhino asset set. The keyboard image comes from the local C14 modular keyboard Blender render. The source models are not bundled with this website.

The interactive split keyboard is a web export of Scholay's local D01 split modular keyboard Blender model. It retains the exterior geometry, original PBR materials, and key legends. Each keycap and its legend share a separate animation group. The website bundles the derived GLB, key mapping, and preview render; the editable Blender source is not included.

The keyboard viewer uses Three.js under the MIT license, retained at `public/models/licenses/THREE-MIT.txt`. Its bundled Draco decoder files are distributed unchanged from Three.js's glTF decoder package under Apache 2.0; the license and source README are retained in `public/models/draco/`.

The Lingxi IME project icon is from the RIMES `Logo/rimes-rhino.png` asset. The four iOS screenshots are native Release simulator renders from 2026-10-06, converted to WebP for this website.

The input-scheme directory is derived from `scholay/rimes`'s `Catalog/input-schemes/index.json`. Each linked ZIP retains its upstream licenses, attribution, pinned revisions, and modification manifest. The website's code does not replace those licenses. Packages without redistribution permission, without host verification, with high resource requirements, or with known incomplete license attachments are linked to their upstream source instead of hosted here. See `docs/input-schemes.md` for the current exclusions and synchronization process.
